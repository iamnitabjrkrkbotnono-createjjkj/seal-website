# Hiyori's Hangout 🦭

A tiny, responsive Hiyori-themed chatroom.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open the repository's **Settings** tab.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to finish deploying. The site URL will appear in the Pages settings.

Note: this first version is a front-end demo. Chat replies are prewritten; it is not connected to a live AI service.

The Hiyori GIF is linked from its Tenor page and credited in the website footer. If you have a favorite Hiyori photo you have permission to use, you can add it to the repository and replace the GIF URL in `index.html`.
